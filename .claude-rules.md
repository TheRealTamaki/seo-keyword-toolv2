# Claude Code Rules - READ BEFORE WRITING ANY CODE

## 🚨 Bug Fixing Protocol (MANDATORY)

When fixing a bug:
1. **Identify the root cause** - Don't just treat symptoms
2. **Implement the fix** - Make targeted changes
3. **Verify with linting** - Ensure code quality
4. **ALWAYS end response with**: A simple one-sentence summary using exactly 3 alarm emojis (🚨🚨🚨)
   - This is **MANDATORY** and must be the very last sentence

Example:
```
🚨🚨🚨 Fixed DataForSEO validation by changing POST body from null to empty array.
```

## 🍎 Platform-Specific Commands

- **ALWAYS provide Mac-specific keyboard shortcuts and terminal commands**
- Use `Cmd` instead of `Ctrl`
- Use macOS-specific paths and conventions
- Example: "Press Cmd+C to copy" NOT "Press Ctrl+C to copy"

## 🔄 Component Reusability

When adding UI elements that repeat between pages:
1. **First**: Check if a shared component already exists
2. **Then**: Either reuse the existing component OR
3. **Refactor**: Extract repeated markup into a new shared component
4. **Never**: Copy-paste the same UI code across multiple pages

## 📝 README File Standards

When creating or editing README files, **ALWAYS add these social media links** at the top of the file, right after the main title:

```markdown
# Project Title

[![Twitter Follow](https://img.shields.io/twitter/follow/YourHandle?style=social)](https://twitter.com/YourHandle)
[![LinkedIn](https://img.shields.io/badge/LinkedIn-Connect-blue)](https://linkedin.com/in/YourProfile)
[![GitHub followers](https://img.shields.io/github/followers/YourUsername?style=social)](https://github.com/YourUsername)

[Rest of README content...]
```

## 🧹 Test File Cleanup

- **Delete any test files after confirming they are no longer needed**
- Don't leave orphaned test files in the codebase
- Always ask for confirmation before deleting if unsure

---

## Checklist Before Committing

- [ ] Bug fixes end with 🚨🚨🚨 summary
- [ ] Commands use Mac-specific syntax
- [ ] No duplicate UI components
- [ ] README has social media links (if applicable)
- [ ] No orphaned test files
